篮球

篮球作为在意志上非常能驱动我的事物，让其变成稳定发展的事物是关键

关于篮球我的文字记录无需太多（通过最近的实践，我对篮球多打，记事本记一记，看看那些走在我前面的人的路）
待学习：

篮球训练内容

每日投篮都需要练，把握好发力
每日运球都需要练，持之以恒

后续技术等稳定再补充

力量训练内容

核心：平板划船
上肢：地雷管肩推
全身：分腿蹲状态下的单挑推举
动态臀桥搭配静态臀桥
下肢和足踝：视频恢复跟练

高脚杯深蹲（足踝恢复了再练）

1、每日轻度打球日（常规天）
✅ 固定顺序：
短轻度足踝激活（5–10 分钟，不练累）
→ 超轻量力量（只做：轻臀桥）
->（轻划船，肩推 / 分腿推举）1 5 7做
→ 轻度投篮 / 运球练习
→ 结束简单拉伸
💡关键：
日常力量只做「稳定养护」，不做发力竭、不加重量，全程保打球力气。

2、每周三【纯强化力量日｜完全不打球】
这天：不碰篮球、不跑跳
完整干你全套：
足踝深度恢复跟练
→ 动态臀桥（加量）
→ 平板 + 划船（加组数）
→ 地雷管肩推（正常强度）
→ 分腿蹲单挑推举（主力强化）
这天专门堆力量、堆肌肉恢复，给周末打球攒底子。

3、周末模式
✅ 轻度激活 + 长时间打球：
赛前短足踝热身
→ 一点点轻臀桥开髋
→ 专心长时间投篮 / 实战
→ 赛后深度拉伸 + 脚踝放松
❌周末不搞任何强化负重力量
